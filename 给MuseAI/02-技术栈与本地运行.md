## 跑起来

要求 Node 20+。

```bash
cd mobile-app
npm install

npm run web        # 浏览器预览，端口 8080
npm start          # Expo Go / 模拟器
npm run typecheck  # tsc --noEmit，改完必须过
npm run lint       # biome check .
npm run lint:fix   # biome check --write .
```

打包相关脚本（需要 `eas-cli` 和 Expo 账号）：

```bash
npm run eas:build:preview:android   # 内部预览包 APK
npm run eas:build:preview:ios
npm run eas:build:prod              # 商店包
```

Web 静态导出：`npm run export:web` → 输出到 `dist-root/`（会顺带跑 `scripts/优化网页首屏.cjs`；Windows 终端若因中文文件名报错，改用 UTF-8 代码页运行）。

## 接口基址怎么改

优先级（`constants/env.ts`）：

1. 运行时环境变量 `EXPO_PUBLIC_API_BASE_URL`
2. `app.json` 的 `expo.extra.ApiBaseUrl`
3. 硬编码兜底 `https://vivodraw.com`

本地联调示例：

```bash
EXPO_PUBLIC_API_BASE_URL=http://192.168.1.10:8000 npm run web
```

**不要**把基址改回旧 IP（那些地址已废弃），统一 `https://vivodraw.com`。
