# 04 · 接口与鉴权

## 一个入口：`lib/http.ts`（71 行，全项目唯一 axios 实例）

```ts
// lib/http.ts:21-28
export const http = axios.create({
  baseURL: API_BASE_URL,          // 来自 constants/api.ts → constants/env.ts
  timeout: API_TIMEOUT,           // 15000ms
  headers: {
    "Content-Type": "application/json",
    "X-Client": "mobile-app",     // 后端只放行带这个头的新前台，缺了会被拒
  },
});
```

**`X-Client: mobile-app` 是硬要求**，后端用它区分新旧前台（阻断旧 Uniapp）。自己写 fetch 也必须带上。

### 请求拦截：token 自动注入

```ts
// lib/http.ts:30-40
const token = useAuthStore.getState().token;
if (token) config.headers.Authorization = `Bearer ${token}`;
// FormData 请求会删掉 Content-Type，交给运行时自己生成 boundary
```

### 响应拦截：只有 `status === 200` 算成功

```ts
// lib/http.ts:42-65
if (data.status === 200) return data;          // 注意：返回的是整个包 {status,msg,data}
const LOGIN_EXPIRED = [410000, 410001, 410002];
if (LOGIN_EXPIRED.includes(data.status)) useAuthStore.getState().logout();
return Promise.reject(new ApiError(msg, data.status, data.data));
// 另外 HTTP 401 也会 logout
```

返回包约定（`lib/http.ts:67-71`）：

```ts
type ApiResponse<T> = { status: number; msg: string; data: T };
```

**业务码 200 才算成功，不是 HTTP 200。** 拿数据要 `res.data`，两层：

```ts
const res = await http.get<ApiResponse<User>>("/api/user/info");
const user = res.data.data;   // 第一层 res 是 http 返回的包，第二层 .data 才是业务数据
```

## 加一个接口（四步，照抄现有写法）

1. `constants/api.ts` 里在 `API_ENDPOINTS` 加常量：
   ```ts
   PRAYER_TODAY: "/api/prayer/today",
   ```
2. 新建 `lib/api/prayer.ts`：
   ```ts
   import { http, type ApiResponse } from "@/lib/http";
   import { API_ENDPOINTS } from "@/constants/api";

   export async function fetchTodayPrayer() {
     const res = await http.get<ApiResponse<PrayerToday>>(API_ENDPOINTS.PRAYER_TODAY);
     return res.data.data;
   }
   ```
3. 新建 `hooks/usePrayer.ts`：
   ```ts
   export function useTodayPrayer() {
     return useQuery({ queryKey: ["prayer", "today"], queryFn: fetchTodayPrayer });
   }
   ```
4. 页面里 `const { data, isLoading } = useTodayPrayer();`

## 错误提示

- 业务错误是 `ApiError`（`lib/http.ts:10-19`，带 `status` / `data`）
- 弹窗统一走 `lib/appAlert.ts`，别直接用 `Alert.alert`（Web 端不支持原生 Alert）
- 加载态用 skeleton / ActivityIndicator，参考 `app/points/` 下任意列表页
