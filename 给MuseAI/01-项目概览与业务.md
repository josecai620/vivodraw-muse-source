# 01 · 项目概览与业务

## 这是什么

VivoDraw（线上 `https://vivodraw.com`），面向美国市场的电商 + 积分/盲盒/小游戏一体的移动 APP。
本仓库是它的**用户前台 APP**（Expo React Native，同时可编译成 Web 站点）。

- 现役版本：`mobile-app/`（内部叫 v4）
- 已停用：`mobile-app-v3/`（不在本次交付里，别参考）
- 后端：PHP 8.1 + ThinkPHP 6，**不在本仓库**，本次也不交付

## 现有业务模块（按 `app/` 目录）

| 目录 | 内容 |

| 顶层单页 | `pearl.tsx`（海底寻珠）、`farm1.tsx`（花园）、`pet-deck.tsx`（宠物世界）、`game-wallet.tsx`、`coin-exchange.tsx`、`point-purchase.tsx`、`wallet.tsx`、`play.tsx`、`pick-your-prize.tsx`、`support.tsx` |

规模：`app/` 158 个 `.tsx`，`components/` 137 个，`lib/` 73 个，`hooks/` 16 个。

## 账号与登录

- 登录态用 **token**（存 SecureStore，Web 端退化到 localStorage，见 `lib/secure-storage.ts`）
- token 放在 zustand 的 `useAuthStore`（`store/auth.ts`），请求由 axios 拦截器统一注入 `Authorization: Bearer <token>`
- 后端返回 410000/410001/410002 或 HTTP 401 时自动登出

## 交付边界（先说清楚，省得后面返工）

1. 本包只有前台 APP。**没有** PHP 后端、数据库、生产 `.env`、支付密钥、推送私钥。
2. 想接真实数据，只能连线上 `https://vivodraw.com`（现在就是这么配的）。
3. 如果要加后端接口，需要另行协调后端，或先在 APP 内做本地优先（AsyncStorage）的方案。
