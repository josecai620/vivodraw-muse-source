# 03 · 代码结构与约定

## 目录

```
mobile-app/
├── app/               # expo-router 路由（文件即路由）
│   ├── _layout.tsx    # 根布局：QueryClient / 字体 / Splash / 全局 Provider
│   ├── (tabs)/        # 底部 5 tab

├── components/        # 组件（137）
│   ├── shared/        # 跨模块共用（含 TabNavIcons 图标）

├── lib/
│   ├── http.ts        # axios 实例 + 拦截器（核心）
│   ├── api/           # 按域拆的接口函数（36 个文件）
│   ├── native/        # push.ts / share.ts / bridge.ts
│   ├── i18n/          # 语言（en + zh-TW）

```

## 约定

- **路径别名**：`@/*` → 项目根。一律 `import { http } from "@/lib/http"`，不要写 `../../../`
- **语言**：注释、文案、业务文件名用中文；代码标识符用英文。给现有代码补注释也用中文
- **类型**：`strict: true`，不要为了过编译加 `any` 或 `@ts-ignore`；确实要绕，写 `// @ts-expect-error 原因`
- **格式化**：biome，缩进 2 空格，行宽 100。提交前跑 `npm run lint:fix`
- **样式**：主用 NativeWind 的 `className`；动画、复杂布局用 `StyleSheet`
- **主题色**：主色 teal `#04A8AE`（`constants/theme.ts` 的 `Colors.primary.DEFAULT`；tailwind 里那个叫 `brand.red` 的其实是同一个 teal，历史命名遗留，别被名字骗了）
- **多语言**：`useTranslation()` + `lib/i18n/locales/{en,zh-TW}.json`。新增文案必须两个语言文件都加 key
- **状态**：
  - 服务端数据 → react-query（`useQuery` / `useMutation`），queryKey 写成数组常量
  - 本地/登录态 → zustand（`store/*`）
  - 持久化 → `lib/secure-storage.ts`（敏感）或 AsyncStorage（非敏感）

## 新增一个页面（最短路径）

1. 在 `app/` 下建文件，例如 `app/prayer/index.tsx` → 路由就是 `/prayer`
2. 需要子页就建目录 + `_layout.tsx`（Stack）
3. 想进底部 tab：改 `app/(tabs)/_layout.tsx` 加一个 `<Tabs.Screen name="prayer" … />`（现有 5 个在第 176–232 行）
4. 图标复用 `components/shared/TabNavIcons.tsx` 的线条风图标组件（28px，描边 1.65/1.9）

## 绝对不要重构的东西

这些是商城核心链路，改了会导致线上白屏/下单失败（项目里有硬性保护清单）：

`constants/api.ts`、`lib/api/points.ts`、`hooks/usePoints.ts`、`hooks/index.ts`、
`lib/api/box.ts`、`hooks/useBox.ts`、`app/box/` 全部。

要加东西就在旁边加新文件，不要改它们的既有导出。
