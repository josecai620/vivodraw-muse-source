## 三句话版本

- 这是个 Expo SDK 54 + expo-router + TypeScript 的商城 App，已有 5 个底部 tab、158 个页面。
- 你要做的是**在它里面加晨祷模块**，共用账号（token 在 `store/auth.ts`）和通知（`lib/native/push.ts`）。
- 商城核心文件（`constants/api.ts`、`lib/api/points.ts`、`hooks/usePoints.ts`、`lib/api/box.ts`、`hooks/useBox.ts`、`app/box/`）**只读不改**，改动会导致线上白屏。

## 五个立刻会用到的文件

| 文件 | 为什么看它 |
| --- | --- |
| `mobile-app/lib/http.ts` | 所有请求的入口，71 行，看懂它就看懂鉴权 |
| `mobile-app/constants/api.ts` | 端点表，加接口从这里开始 |
| `mobile-app/app/(tabs)/_layout.tsx` | 底部 tab，加晨祷 tab 要改这里（第 176–232 行是现有 5 个） |
| `mobile-app/lib/native/push.ts` | 通知权限 / Expo token / 本地通知，晨祷提醒直接复用 |
| `mobile-app/constants/theme.ts` | 主色 teal `#04A8AE`，新页面配色照它来 |
